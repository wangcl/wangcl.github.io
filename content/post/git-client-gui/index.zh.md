## 使用环境
- 操作系统：windows

  主要使用环境是 windows，计算机包括 windows 笔记本(多为 1920 * 1080 分辨率)、主机 + 外置显示器(1080/1200, 2k, 4k)

- git for windows portable

  软件如果有便携版，优先使用便携版
